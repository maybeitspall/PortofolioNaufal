# Design System Document
## Liquid Glass Aesthetics — Naufal Fadhillah Portfolio

---

## 1. Design Vision
- **Theme**: Liquid Glass (Refractive dark mode with translucent glass cards, neon indigo/violet/cyan glows, and dynamic ambient fluidity).
- **Typography**: `Inter` (geometric, clean headings) & `DM Sans` (readable, modern body text).
- **Core Aesthetics**:
  - Translucent surfaces with soft frosted blur (`backdrop-filter: blur(16px)`).
  - Glowing borders and dual-tone linear gradients.
  - Interactive 3D tilt on card hover with dynamic specular lighting.
  - Fluid background blobs interacting smoothly on mouse motion.
