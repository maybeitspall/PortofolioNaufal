Latar Belakang & Tujuan Proyek

Proyek Innovilage 2025 ini bertujuan membangun ekosistem digital untuk mendampingi petani nilam di Desa Teuladan, Kec. Seulimum, Kab. Aceh Besar. Sistem ini menyediakan pemantauan metrik pertanian secara presisi untuk memitigasi gagal panen dan memaksimalkan hasil minyak nilam berkualitas tinggi.

Peran & Tanggung Jawab (Full Stack Developer)

Sebagai Full Stack Developer, Naufal bertanggung jawab dari hulu ke hilir:

  • Merancang antarmuka dashboard responsif berbasis HTML, CSS, dan JavaScript murni yang mudah dipahami oleh petani dan pihak pengelola.
  • Membangun backend service menggunakan FastAPI dengan database PostgreSQL untuk manajemen produksi dan riwayat kesehatan tanaman.
  • Melatih dan mengintegrasikan model machine learning klasifikasi penyakit tanaman nilam berbasis Keras (Computer Vision).
  • Memastikan sinkronisasi data analitik dan hasil diagnosa citra dapat diakses secara otomatis dan real-time.
