# Naufal Fadhillah — Liquid Glass Portfolio Website

Interactive, modern, and high-performance personal portfolio website built with a **Liquid Glass** aesthetic (Dark mode glassmorphism + ambient fluid physics).

🌐 **Live Demo:** Ready for GitHub Pages deployment.

---

## 🚀 Features
- 💎 **Liquid Glass UI**: Frosted glassmorphism panels, specular light reflections, neon gradients.
- 🌊 **Canvas Liquid Physics Engine**: Dynamic floating ambient fluid blobs with mouse repulsion.
- 📱 **Fully Responsive**: Mobile drawer navigation, adaptive layouts from 320px to 4K displays.
- ⚡ **Zero-Dependency Static Build**: Pure HTML5, Vanilla CSS3, and ES6+ JavaScript.
- 🎯 **Interactive Project Case Study**: Interactive modal showcase for **NILAMTRACE** (Nilam crop analytics & CV detection dashboard).
- 🕒 **Work & Education Timeline**: Detailed overview of supervisory & developer experience.
- 📬 **Direct Contact Integration**: WhatsApp, Email, GitHub, LinkedIn, Instagram, and Contact Form.

---

## 🛠️ Tech Stack
- **Structure:** HTML5 Semantic Markup
- **Styling:** Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid & Flexbox, Keyframe Animations)
- **Interactions:** Vanilla JavaScript (Canvas API, IntersectionObserver, 3D Tilt, Typewriter, Modals)
- **Icons:** FontAwesome 6
- **Typography:** Inter & DM Sans (Google Fonts)

---

## 📦 How to Deploy on GitHub Pages
1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "Initial release of portfolio website"
   git branch -M main
   git remote add origin https://github.com/maybeitspall/Portofolio.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Branch**, select `main` and root `/`
   - Click **Save**. Your site will be live at `https://maybeitspall.github.io/Portofolio/`!
